# Handy Links

Django Based web app to save and share your links

## How to run

    npm run dev
    python manage.py runserver_plus --cert-file cert.crt

## Access url

> https://localhost:8000
> https://mysite.com:8000/home/

## Python version
    v3.13.0
## Node version
    v22.12.0
## Django version 
    v5.1.4
